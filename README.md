# КТ5 — Прогнозирование стоимости недвижимости (California Housing)

Учебный проект университета «Туран»: четыре варианта регрессионных моделей и веб-интерфейс Streamlit. Используется набор California Housing 1990 года; прогнозируется **медианная стоимость жилья на уровне группы кварталов**, не цена конкретной квартиры в Казахстане.

## Файлы

- `app.py` — веб-приложение Streamlit.
- `KT5_models_and_preprocessing.joblib` — обученные модели и объекты предобработки. **Этот файл включён в полную версию архива. При загрузке на GitHub используется Git LFS.**
- `KT5_California_Housing.ipynb` — Google Colab: исследование, обучение трёх исходных моделей и оптимизация Random Forest.
- `requirements.txt` — библиотеки Python (рекомендуется Python 3.12).
- `examples/sample_data.csv` — 10 тестовых записей без ответов для проверки пакетного прогнозирования.
- `examples/invalid_data.csv` — 5 записей без MedInc для проверки обработки ошибок.
- `examples/reference_predictions_kt5.csv` — эталонный вывод, полученный при тестировании КТ5.
- `check_project.py` — проверка файла моделей и одного типового прогноза.
- `run_windows.bat` — запуск на Windows; `install_windows.bat` — установка библиотек.
- `make_full_zip.py` — создание **полного** архивного комплекта после добавления `.joblib`.
- `DEPLOY.md` — инструкция публикации GitHub → Streamlit Community Cloud.

## Запуск на Windows

1. Распакуйте архив в папку, например `C:\Users\...\Desktop\KT5_Housing`.
2. Проверьте, что `KT5_models_and_preprocessing.joblib` находится **рядом с `app.py`**. В полной версии архива модель уже включена.
3. Установите Python 3.12, если он отсутствует.
4. Запустите `install_windows.bat` для установки библиотек (интернет понадобится один раз).
5. Запустите `run_windows.bat` или в командной строке выполните:

   ```cmd
   py -3.12 -m streamlit run app.py
   ```

6. Откройте `http://localhost:8501`. Окно командной строки должно оставаться открытым.

## Что проверить

В выпадающем списке ожидаются **четыре модели**: Linear Regression, Ridge Regression, Random Forest Regressor, Random Forest Optimized. По умолчанию — Random Forest Optimized.

- На вкладке «Ручной прогноз» оставьте стандартные значения и нажмите «Рассчитать стоимость». Ранее оптимизированная модель выдала около **221 818,03 USD** (на тех же данных и с тем же файлом модели).
- На вкладке «Загрузка CSV» загрузите `examples/sample_data.csv`. Должно обработаться 10 строк; можно скачать файл прогнозов.
- Для проверки ошибок загрузите `examples/invalid_data.csv`: программа должна сообщить об отсутствии признака `MedInc`.
- На вкладке «Сравнение моделей» отображаются MAE, MSE, RMSE, R² и графики всех четырёх моделей.

## Результаты исследования

| Вариант | MAE | RMSE | R² |
|---|---:|---:|---:|
| Linear Regression | 0,5031 | 0,6801 | 0,6470 |
| Ridge Regression | 0,5031 | 0,6801 | 0,6470 |
| Random Forest Regressor | 0,3294 | 0,5050 | 0,8054 |
| Random Forest Optimized | 0,3283 | 0,5050 | 0,8054 |

В КТ5 CV RMSE уменьшилась с 0,5162 до 0,5116. Разница RMSE и R² на тестовой выборке после округления незначительна.

## Создание полного ZIP для преподавателя

Полная версия архива уже содержит модель. Чтобы создать повторную копию полного архива, **дважды щёлкните `make_full_zip.bat`** либо выполните:

```cmd
py -3.12 make_full_zip.py
```

Рядом появится `KT5_Housing_FULL.zip`, в который **уже включена модель**. Этот ZIP можно отдать преподавателю для локального запуска.

## Публикация в интернете

Читайте `DEPLOY.md`. Публичная ссылка не появится сама: сначала нужно загрузить проект с моделью в GitHub и развернуть через https://share.streamlit.io/. Файл модели ~90 МБ превышает лимит веб-загрузки GitHub 25 МиБ: загружайте репозиторий через Git + Git LFS, а не через кнопку Upload files.

## Важно

- Прогноз — учебный результат для California Housing **1990 года**. Не применять для актуальной оценки конкретного объекта.
- Никогда не загружайте `.joblib` из непроверенных источников: десериализация объектов может выполнять код.
- Не размещайте токены, пароли и персональные данные в GitHub.
- При изменении версии scikit-learn для сохранённых моделей возможны предупреждения о несовместимости.

## Быстрая публикация на GitHub

Создайте пустой репозиторий на https://github.com/new (без README) и запустите `upload_to_github.bat` из распакованной папки. Скрипт проверит Git и Git LFS, попросит **URL вашего репозитория** и только после отдельного подтверждения выполнит `git push`.
Затем на https://share.streamlit.io выберите ваш репозиторий, ветку `main`, `app.py` и Python 3.12. См. подробности в `DEPLOY.md`.
